`obstrans` is a high-performance resumable-transfer CLI built on Huawei Cloud Object Storage Service (OBS). It supports multipart upload, ranged download, bucket-to-bucket migration, and distributed cluster transfer orchestrated by a message queue. It fits large-scale data migration, cross-region sync, and reliable large-file transfer.
